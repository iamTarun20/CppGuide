When using CPP we use 2 types of memory :-

STACK AND HEAP

1:- STACK
use for the fast extract , generally small and follow principle of first in last out,
It is smaller in size 
if given large size of the array then "STACK OVERFLOW" error would occur.

Life cycle:- only till the function remains , once it ends stack is empty then


2:- HEAP
Large pool of memory , 
Allocates when we use "NEW" keyword, also called dynamic memory allocation 
allocation runtime per hota he , 
we can allocate large pool of memory
but it is manueal so we need to deallocate also by using DELETE keyword.
